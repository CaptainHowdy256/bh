Sorry, we have no more heads left.  Game's over.  Get out of here.  Go home. 

 

We hope you enjoyed the game.  Back in 1999 and 2000, our staff1 worked long and hard on this project and had lots of fun doing it.  It was a labor of love and was created solely for your enjoyment.

Funny thing, when we uploaded the game back in the day, we did not anticipate that it would require any maintenance. So we never updated it. After a few years, web browsers changed and the game wouldn't work with Internet Explorer or Firefox unless you installed the stand alone JAVA app. Then, around 2010, the game stopped working completely.

Between the time when the game went live and the time when it began to break down,  our company2 changed it's name to Twitter3 and we all became filthy stinkin' rich. So we all just kind of forgot about the game as we spent our days sipping Pina Coladas on our private Caribbean island.

But every once in a while, one of the original developers would remember this dead game taking up space on the internet. Right around the middle of 2015, we decided to either take the game down or fix it so it would work again.  We went with fixing it because it was pretty damn easy to do that and also because, why not?
